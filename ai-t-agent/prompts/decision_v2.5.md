# Decision Prompt v2.5

> 生效位置：`src/agent/decision/engine.py` `_build_prompt` + `src/agent/decision/planner.py`（代码 f-string 为唯一生效版本，本文档仅存档）
> 上线时间：2026-08-17 夜（8/18 首个生效交易日）

## 背景（8/17 复盘发现的问题）

8/17 全天 238 条 thought 去重后仅 8 种，最高频单条重复 204 次（86%分钟逐字相同），模型只引用 Planner 计划中的 MA20/支撑，无视大盘/已成交/T预算/风控反馈。根因：
1. Planner 计划是无条件触发式表述（"接近MA20时买入"），决策模型照单复读
2. temperature=0.1 + 每分钟输入几乎不变 → 固定输出吸引子
3. 8/17 账户状态冻结（被拒买单不改变展示状态），Prompt 无"变化量"，模型无新信息可引用
4. 弱模型注意力集中于行动指令（计划+行情区双重曝光），忽略上下文区块（lost in the middle）

## v2.5 变更记录（2项）

### 1. Planner 计划条件式表述（planner.py）
Prompt 新增"计划编写规范"：
- trade_plan 必须写成"当<状态条件>且<价格条件>时，执行<动作>"，禁止无前提触发式语句
- 买入条件必须含仓位前提（已达目标仓位则计划不得含买入动作）
- 卖出条件必须含持仓前提（无持仓则计划不得含卖出动作）
- 每条计划需说明：目标仓位、最多交易笔数、触发价格区间、不满足条件时观望

### 2. 硬性约束置顶区块（engine.py）
决策 Prompt 开头（市场环境之前）新增 `## 硬性约束` 区块，动态计算：
- 无持仓 → "禁止发出SELL"
- 持仓但可卖=0（T+1锁定）→ "禁止发出SELL"
- 不可买入（现金不足/仓位上限）→ "禁止发出BUY"；可买时给出"最多可买N股"
- 当日成交笔数达到 max_trades_hint → "停止交易只可HOLD"
- 风控状态 HALT/LIQUIDATE → 全局禁买/禁一切操作
