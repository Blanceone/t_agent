# Decision Prompt v2.20 / Planner v1.5

日期：2026-08-28 晚（策略正逆向 + 关键字审查）

## 相对 v2.19

v2.19 清仓后仍以「无持仓」开头，规则仍写「必须出现在持仓区块」，模型会按空仓建仓。本版只改口径，不改决策权。

1. 文首：未接回=接回不是建仓；仓位相对目标、区间位置是数据不是必须减仓。
2. 清仓未接回行改为「持仓0股/可卖0股」，硬约束与行情禁卖同步，不再用「无持仓」当主标签。真·空仓仍写「无持仓」+ 建仓句。
3. 规则 5/6/10：可卖>0 才能卖；持仓0股未接回行不能卖；不要把未接回当成从未持仓的建仓。
4. 单测矩阵：持仓可卖 / 部分卖 / 清仓未接回 / 次数用尽未接回 / 接回后 T+1 / 真空仓，分区块校验「建仓/无持仓/必须卖」不得串台。
