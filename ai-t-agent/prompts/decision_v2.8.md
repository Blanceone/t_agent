# Decision Prompt v2.8

日期：2026-08-20 晚（盘后部署，8/21 首个生效交易日）

## 背景

8/20 实盘暴露"复读循环"：09:30/09:31 两笔 SELL 清空 200 股后，模型在剩余 236 分钟内
每分钟输出几乎相同的 thought（"由于目前无持仓…符合卖出条件"）并反复发 SELL，
全天 231 次被风控拒绝（INSUFFICIENT_SELLABLE），置顶硬约束与风控反馈均未能终止循环。

根因（机制层，非 v2.7 引入）：
- 空仓 + 计划 SELL_FIRST_THEN_BUY_BACK + T 预算未耗尽（2 < 上限）→ Prompt 中
  "计划说先卖"与"无持仓禁止SELL"形成矛盾信号，全系统唯一的停止信号（预算耗尽约束）未触发
- GLM-4-Flash 在 temperature 0.1 + 每分钟输入几乎不变的条件下进入确定性复读
- 4 次买回尝试均与垃圾 SELL 同分钟成对输出，被矛盾过滤器双双丢弃（另行修复项）
- 对照 8/18：同为"先卖后买"计划 + 空仓，模型推理健全（"无持仓，且无股可卖，因此无交易决策"），
  说明该缺陷是概率性的模型行为退化，需要事实性兜底降低触发概率

## 设计原则（延续用户确立的原则）

只给数据、不干预判断，除非必要的兜底。本次注入属"必要兜底"：
它是账户事实的陈述（无股可卖 → 计划的卖出步骤不可执行），
与既有的"无持仓禁止SELL"同属事实硬约束，不替代模型对价格/时机的任何判断。

## v2.8 变更记录（2 处）

### 1. engine.py 硬性约束区：空仓 + 先卖后买计划时追加事实说明
```
{code} 无持仓：计划中的卖出步骤不可执行（无股可卖），
仅可执行计划中的买入建仓部分，或不满足买入条件时观望
```
- 触发条件：该标的无持仓 且 计划 t_strategy == SELL_FIRST_THEN_BUY_BACK
- 目的：消解"计划说先卖"与"无股可卖"的指令矛盾，打断复读循环的诱因
- 边界：不注入任何价格/时机判断；BUY_FIRST_THEN_SELL / WAIT 策略不受影响

### 2. 可观测性（同批部署，非 Prompt 内容）
- scheduler.py：Planner 完整输出落日志（event=planner_output，含策略/预算上限/
  trade_plan 全文/目标仓位/风险），此前计划内容完全不可追溯
- replay/store.py + tick.py + engine.py：每 Tick 决策全量快照落盘
  data/replay/{日期}/prompts.jsonl（完整 Prompt + LLM 原始响应 + 解析决策 +
  矛盾过滤记录 + 执行/拒单明细），此前 ReplayStore 从未被调用
- engine.py：新增 _last_prompt / _last_raw 捕获，供 Replay 落盘使用

## 验证

- 55 项单元测试全部通过
- 冒烟测试：空仓 + SELL_FIRST 计划 → 硬性约束区含"计划中的卖出步骤不可执行"；
  持仓时不注入；BUY_FIRST 策略空仓时不注入
