# Decision Prompt v2.21 / Planner v1.5

日期：2026-09-01 晚（未接回负数 / 加仓被叫成接回）

## 相对 v2.20

v2.20 持仓行只要今日有买或卖就打印 `未接回 = 已卖 − 已买`。9/01 无卖、买 100 股，写成未接回 −100，模型把加仓叫成接回。本版只改正数口径，不禁止加仓、不改 Planner。

1. 持仓行：已卖>已买才写未接回正数；已卖>0 且已买≥已卖写「接回已闭环」（买超则加净买入）；今日无卖出只写「今日已买，不是接回」。不打印 0 或负数。
2. 文首 / 规则 3 / 规则 10：未接回仅正数；无未接回时买入不是接回（已持仓为加仓，空仓为建仓）。
3. 清仓未接回幽灵行、真空仓建仓、接回≠建仓关键字矩阵不变。
