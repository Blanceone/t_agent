# Decision Prompt v2.13 / Planner v1.1

日期：2026-08-26 晚（对照「只给数据、判断留给模型」，待 8/27 生效）

## 相对 v2.12

v2.12 代码闸保留。本版只改事实表述、补客观数据、去掉替模型选价的范例。
不写入成交价，不保底做T次数，不把「弹回开盘价」写成策略。

### 1. 硬约束：可执行 ≠ 必须卖（engine.py）
先卖后买且可卖>0 时，由「当前可执行步骤：卖出」改为：
「若本分钟交易，只允许SELL（可卖N股），不是必须卖出」。
计划行「当前可执行」同步。

### 2. 禁买原因拆开
不再写「现金不足或已达仓位上限」。按购买力不足 / 单票上限剩余不足100股分写。

### 3. 预计算补相对今开、日内最高、自最低回升（纯数值）
不添加「反弹/靠近」等判断词。

### 4. 今日计划降为开盘框架
决策 Prompt 写明：计划是开盘偏好，本分钟仍看当前行情与预计算；计划价位是参考不是必须成交价。

### 5. Planner v1.1
持仓区增加今开/昨收/均价/最高/最低。编写规范去掉「卖在MA5 / 买在MA20」范例，价格条件由模型自选参考位。

不改：不因仓位高于目标而禁卖；不做T次数保底；不把 VWAP/开盘价写成默认卖点。
